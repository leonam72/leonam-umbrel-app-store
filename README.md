# Leom App Store

Community App Store for umbrelOS.

## Add to your Umbrel

1. Open your Umbrel dashboard
2. Go to **App Store**
3. Open the **⋮** menu (three dots) and choose **Community App Stores**
4. Click **Add Store**
5. Paste this repository URL:

```
https://github.com/leonam72/leonam-umbrel-app-store
```
